# Triage labels

Use the canonical role name as the value of an implementation ticket's
`Status:` line, for example `Status: needs-info`.

| Role and label | When to use it |
| --- | --- |
| `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | The reporter needs to supply more information. |
| `ready-for-agent` | The ticket is specified well enough for an agent to implement independently. |
| `ready-for-human` | Implementation requires a human. |
| `wontfix` | The maintainer has decided to close the issue without implementing it. |

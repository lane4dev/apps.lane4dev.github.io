# Adding another application

The project separates global site information, application metadata, landing
pages, and application-specific legal pages.

## 1. Add application metadata

Add a new top-level key to `_data/apps.yml`:

```yaml
feather-ledger:
  name: "Feather Ledger"
  slug: "feather-ledger"
  short_description: "A concise description."
  status: "Coming soon"
  store_enabled: false
  store_url: ""
  features:
    - title: "Feature"
      description: "Description."
```

## 2. Add a collection document

Create `_apps/feather-ledger.md`:

```markdown
---
title: "Feather Ledger"
layout: app
app_key: "feather-ledger"
weight: 20
permalink: /feather-ledger/
description: "A concise description."
lang: en
translation_key: feather-ledger
alternate_lang: zh-CN
alternate_url: /zh/feather-ledger/
x_default_url: /feather-ledger/
---
```

The root application directory lists `_apps` collection documents
automatically.

## 3. Add application pages

Create:

```text
apps/feather-ledger/
├── privacy.md
├── terms.md
├── account-deletion.md
└── support.md
```

Each page should include `app_key: "feather-ledger"` and use either the
`app-page` or `legal` layout.

## 4. Add navigation only when needed

The global menu should remain small. Add a direct application link to
`_data/menus.yml` only for prominent applications. Application-specific
navigation is generated by `_includes/app-nav.html`.

## 5. Add the Chinese version

Add translated presentation data to `_data/apps_zh.yml`, then create
`_apps/feather-ledger-zh.md` with `lang: zh-CN` and a
`/zh/feather-ledger/` permalink. Add translated legal and support pages under
`zh/feather-ledger/`. Pair every translated page with the same
`translation_key` and reciprocal `alternate_url` values; these generate the
language switch and `hreflang` metadata.

Shared interface text belongs in `_data/i18n/en.yml` and
`_data/i18n/zh-CN.yml`. Add prominent Chinese navigation entries to
`_data/menus_zh.yml`.

## 6. Validate and build

```bash
python scripts/validate_site.py
bundle exec jekyll build
```

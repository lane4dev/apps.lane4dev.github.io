本政策说明你使用章节速览（以下简称“扩展”）时，扩展如何处理信息。本政策适用于本扩展；
第三方网站、AI 服务提供方和浏览器服务有各自的政策。

## 扩展处理的信息

- **网页内容和网站信息：** 在已启用的 HTTP 和 HTTPS 网站上，扩展访问页面（包括主机名、标题和文章内容），以查找章节并放置摘要按钮。页面内容可能包含个人、机密或其他敏感信息。
- **你提供的设置：** 包括 AI 服务提供方、模型、API 密钥、自定义端点、提示词、目标语言、网站允许名单或阻止名单、显示语言和外观偏好。
- **摘要请求和结果：** 当你请求摘要时，扩展会准备所选章节及其子章节的提取文本，以及配置的提示词和目标语言。所选 AI 服务会返回摘要或错误信息。
- **支持沟通：** 如果你联系我们，我们会收到你选择在消息中提供的信息。

## 信息的使用与共享

扩展在你的浏览器中处理网页内容以识别文章章节。只有当你点击摘要按钮或重试已有摘要时，
扩展才会发送摘要请求；它不会仅因为你访问页面就自动发送页面以生成摘要。对已识别的主标题
发起的请求可能包含提取出的文章内容。提取内容可能包括你未预期的内容，因此在敏感页面上请谨慎使用。

摘要请求会发送至你在设置中选择的 AI 服务提供方和端点。支持的服务包括 OpenAI、Google Gemini、
Anthropic、DeepSeek、阿里云百炼（Qwen）和 Ollama。如果配置自定义端点，该端点的运营方将收到请求。
所选服务会收到提取的内容、提示词和模型请求，以及需要时提供的身份验证信息。根据其自身的数据处理方式，
该服务也可能收到你的 IP 地址等网络和请求元数据。

Ollama 默认使用本地端点。如果你配置远程端点，请求将发送至该端点。AI 服务提供方和端点运营方自行
决定其接收信息的保留、安全和使用方式；发送内容前请查阅其条款和隐私政策。扩展本身无法控制或删除
这些第三方保留的信息。

扩展代码直接向所选服务提供方或端点发送摘要请求；它不包含由开发者另行运营的摘要服务器或分析服务。
如果你联系我们，我们会使用你的消息进行回复并提供支持。

## 存储和保留

扩展将设置（包括 API 密钥）保存在浏览器的扩展同步存储中。启用浏览器同步时，浏览器可能将这些设置
同步到你登录的其他浏览器。同步存储并非安全密钥库；请保护好浏览器配置文件，并在服务提供方支持时
使用密钥限制。

只要相关扩展组件仍处于活动状态，提取的章节和生成的摘要就保留在打开的页面中。扩展不会有意将它们
作为摘要历史保存在扩展存储中。关闭页面或在该网站上禁用扩展会移除页面内组件，但不会删除 AI 服务
已收到的数据或你已复制到剪贴板的内容。

设置会保留在扩展存储中，直到被修改或移除。你可以在扩展中更改设置，并通过浏览器移除扩展。
浏览器同步行为和其他设备上的副本由浏览器控制；移除同步数据时请查阅浏览器设置和文档。
较早安装的版本也可能在扩展存储中保留旧配置值。如需使 API 密钥失效，请通过服务提供方撤销或轮换密钥。

## 你的选择

- 使用允许名单或阻止名单为网站启用或禁用扩展，或通过浏览器管理网站访问权限。
- 在请求摘要前选择服务提供方、模型和受支持的端点。
- 避免请求摘要处理你不希望发送给所选服务提供方的信息。
- 更改或移除设置、卸载扩展，并就 AI 服务持有的数据联系相应服务提供方。
